# MacDonald's Food Analysis (Power BI Project)

This project presents a Power BI dashboard that explores the nutritional content of various MacDonald's menu items — helping users understand calorie breakdowns and health metrics at a glance.

## 📊 Dashboard Features:
- Nutritional insights by category (Calories, Fat, Carbs, Protein)
- Highest and lowest calorie items
- Category-wise average nutritional values
- Interactive slicers for deep-dives

## 🔧 Tools Used:
- Microsoft Power BI
- DAX Measures
- Data Cleaning and Modeling
- Visual Analytics

## 📁 File:
- `MacDonald_s Food Analysis.pbix`: The full interactive Power BI dashboard

## ✅ Learnings:
- Developed visual storytelling using nutrition data
- Gained hands-on experience in report building, DAX, and interactivity
